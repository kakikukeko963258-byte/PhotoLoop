# 写真リスニング / PhotoLoop

iOS 16以降のiPhone用。添付された写真1〜3の英文（それぞれ1〜4節）を収録しています。

- 写真ごとに英文を英語音声へ変換し、端末のキャッシュへ保存
- 写真単位の無限ループ、再生・一時停止、15秒移動、再生位置の変更
- 0.7〜1.3倍速、英文表示
- 1〜180分のスリープタイマー（停止時刻で一時停止）
- 音声作成後のバックグラウンド再生、ロック画面の再生・停止
- イヤホン取り外しと音声割り込み時は一時停止

## WindowsからIPAを入手

1. このフォルダー全体をGitHubリポジトリのルートへpushします。
2. Actions → Build iPhone IPA → Run workflow。mainへのpushでも実行されます。
3. 完了した実行のArtifactsから `PhotoLoop-AltStore` をダウンロードし、ZIPを展開します。
4. `PhotoLoop.ipa` をiPhoneのAltStoreの「My Apps」→「＋」で選択します。通常のAltStore/AltServerの署名・インストール手順に従ってください。

GitHubのmacOS 15 runner上でXcodeGenとXcodeを使って署名なしの実機用アプリをビルドし、Payload形式のIPAを作ります。Appleの証明書をGitHubに登録する必要はありません。AltStoreがインストール時に再署名します。

## 使い方

写真を選び、中央の再生ボタンを押します。初回は音声の作成が完了するまでアプリを開いてお待ちください。英語音声はiOS標準のen-US音声を使います。必要な音声が端末にない場合は、iPhoneの設定から英語の読み上げ音声を追加してください。キャッシュがiOSによって削除された場合は再作成します。

「この写真をループ再生」をオンにすると、選んだ写真の1〜4節を繰り返します。「タイマー開始」で指定時間後に停止します。写真を変えてもタイマーは継続します。タイマーは一時停止中も時間が進みます。停止後は再生ボタンで再開できます。

音声作成はネットワークサービスやAPIキーを使いません。初回の音声作成中は写真の切り替えを無効にしています。

## 検証

GitHub Actionsで実機向けコンパイルを実行します。iPhone/AltStoreでの実機確認は別途必要です。写真3つそれぞれの全文再生、ループ境界、画面ロック中のタイマー停止、イヤホン取り外し、電話後の再開、速度変更を確認してください。
